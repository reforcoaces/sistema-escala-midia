      Aniversariantes

      Próximos aniversários com base na data de nascimento cadastrada em Voluntários. Para parabenizar a equipe no Discord no dia, configure o webhook do canal abaixo.

      Webhook definido pela variável de ambiente DISCORD_WEBHOOK_URL no servidor (ex.: Render → Environment). O campo acima fica desativado; os envios usam sempre esse URL.

      O envio automático pode ser feito com uma tarefa agendada (cron / Agendador do Windows) que chame POST /api/birthdays/notify-today com corpo JSON vazio, uma vez por dia.
